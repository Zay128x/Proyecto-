# Proyecto Musical

El proyecto principalmente consiste en una de mis pasiones que es la música. Basándome en eso, mi programa tratará de del llamado Higher or Lower, el cual se utiliza en varios videos de YouTube en diferentes ámbitos, pero esta vez orientado a la música.  se que en el momento se pensaría que esta idea está más basada, en POO en java mas que Python, sin embargo se usarán listas y estructuras las cuales le dan un sentido por la cual esta en Python. Habrá diferentes épocas (principalmente del genero que me gusta) y diferentes modos con personalización en cada uno de ellos de juego: una de ciertas canciones quién tiene más visitas (A o B) o que artista tiene mas oyentes mensuales, se podrá ir intercalando ( cual mas o cual menos).
Se podrán aplicar filtros de épocas, dificultades de la cpu y otros modos como algún endless o acomodar 4 canciones de un mismo genero para saber cual es mas top. También se podrán guardar las puntuaciones para la rejutabilidad.
Me parece interesante mi proyecto debido a las posibilidades que prácticamente son infinitas la rejutabilidad y dificultad que puede tener en poder programarlo sin errores.
logica algoritmo proyecto
1. El usuario empezara el programa con el menu principal con los modos de juego
2. Elegirá el nivel de dificultad y filtros de la musica
3. el programa mostrara al usuario al seleccionar al azar canciones para que elija cual piensa que tiene mas reproducciones
4. el sistema comparara los datos reales y al final determinara si gano la cpu o el usuario
5. finalmente mostrara un resumen final de la puntuacion del usuario
